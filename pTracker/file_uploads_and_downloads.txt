Created file_manager.py

I have created a brand new, production-ready utility class and saved it to **`pTracker/common/file_manager.py`**!

Here is how I designed it specifically to handle your application's architecture:

### Key Features of `FileManager`:
1. **Dynamic Toggling**: It automatically checks `settings.FILE_UPLOAD_MODE`. If it's set to `"S3"`, it uses `boto3`. If not, it falls back to your local file system automatically.
2. **Absolute Path Sanitization (`_get_s3_key`)**: Since your app passes absolute paths (e.g., `/var/www/dm_ptracker/confidential_docs/file.pdf`), the wrapper safely strips out the root prefixes when uploading to S3, ensuring clean bucket keys!
3. **Built-in Fernet Encryption**: I included `upload_encrypted_file` and `read_encrypted_file` methods. This means you no longer need to manually manage the `Fernet` logic inside your business layers!

### Example: How to refactor your current code

**Before (Your current code in `user_management_helper_bl.py`)**:
```python
def save_relieving_letter(self, emp_id, base64_relieving_letter):
    obj_doc = str(base64_relieving_letter).replace("data:application/pdf;base64,","")
    fileName = uuid.uuid4()
    
    # Manual Encryption and Open
    encrypted_content = self.__fernet.encrypt(obj_doc.encode())
    file_path = os.path.join(settings.CONFIDENTIAL_DOCS, f"relieving_letters/{fileName}.pdf")
    with open(file_path ,'wb') as f:
        f.write(encrypted_content)
        f.close()

    return f"{fileName}.pdf"
```

**After (Using your new `FileManager`)**:
```python
from pTracker.common.file_manager import FileManager

def save_relieving_letter(self, emp_id, base64_relieving_letter):
    obj_doc = str(base64_relieving_letter).replace("data:application/pdf;base64,","")
    fileName = uuid.uuid4()
    file_path = os.path.join(settings.CONFIDENTIAL_DOCS, f"relieving_letters/{fileName}.pdf")
    
    # Let the FileManager handle the encryption and the S3/Local routing!
    FileManager().upload_encrypted_file(file_path, obj_doc.encode())

    return f"{fileName}.pdf"
```
